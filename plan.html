📅 四年分阶段规划

点击切换各学年详细规划。每一年都有明确的核心任务与可交付成果。

大一 · 筑基期

关键词：适应大学生活、打好数学基础、建立编程思维、探索方向

📚 课程学习重点

  • 数学分析 / 高等数学 — 统计学的根，要真正理解极限、积分、级数的直觉
  • 线性代数 — 矩阵运算、特征值、SVD，后续机器学习的骨架知识
  • 概率论 — 贝叶斯公式、大数定律、中心极限定理要烂熟
  • 计算机基础 / Python 入门 — 从 Jupyter Notebook 开始写第一行代码
  • 大学英语 — 四级必须过，目标 550+

🛠️ 课外自学路线

  • Python 基础语法 → NumPy → Pandas → 简单的数据清洗与可视化
  • 每天 LeetCode 刷 1 道简单题，重点：数组、哈希表、字符串
  • 学习 Markdown + Git / GitHub 基本操作，开始维护个人笔记仓库
  • 关注 Kaggle 入门竞赛，看懂 Titanic 项目的分析思路
  • 加入学校的数据科学/数学建模社团

📊 推荐进度

Python 基础大一上完成
Pandas 数据处理大一寒假
数学建模入门大一下

🏆 可交付成果

通过 CET-4（550+）计算机二级（Python）GitHub 个人主页建立完成 1 个数据分析小项目高数/线代/概率论 GPA ≥ 3.3

⏳ 时间线

秋季学期 打基础
紧跟课堂 + 晚自习巩固数学 + 周末学 Python 基础（每天 1–2h 编程练习）
寒假 关键窗口
集中攻克 Pandas 数据处理，做一个数据分析小项目并发布到 GitHub
春季学期 开始实战
参加数学建模校赛 / 五一建模联赛练手，报计算机二级，刷英语六级词汇
暑假 拓展视野
学习 Tableau 入门 + 完成 1 个可视化项目；读 1 本数据分析书

大二 · 进阶期

关键词：数理统计深化、SQL 掌握、竞赛起步、工具链成型

📚 课程学习重点

  • 数理统计 — 参数估计、假设检验、方差分析、回归分析（面试高频考点）
  • 数据库原理 — 关系模型、范式、ER 图，结合 SQL 实操
  • 多元统计分析 — PCA、因子分析、聚类分析、判别分析
  • Python 数据分析进阶 — Scikit-learn 入门、特征工程基础
  • 大学英语六级 — 争取一次通过，目标 500+

🛠️ 课外自学路线

  • SQL 从入门到熟练：LeetCode SQL 题库 + HackerRank + 牛客网 SQL 实战（每天 3 道）
  • Pandas 进阶：groupby、merge、pivot、apply 链式操作、窗口函数
  • 系统学习 Tableau / Power BI，做出 3+ 个数据分析仪表板
  • 完成 Kaggle 上 2 个竞赛（Titanic + House Prices），尝试进入前 30%
  • 学习完整的分析报告写法：描述统计→推断统计→可视化→结论建议

📊 推荐进度

SQL 熟练大二上完成
数理统计掌握全年
Tableau/Power BI大二下

🏆 可交付成果

通过 CET-6（500+）SQL 达到面试水平Kaggle 前30%×2Tableau仪表板×3数理统计 GPA ≥ 3.5数学建模省级奖项

⏳ 时间线

秋季学期（9–12月）竞赛+SQL
课堂重点攻克数理统计；参加全国大学生数学建模竞赛（9月）；系统学 SQL
寒假（1–2月）Kaggle集训
完整做 2 个 Kaggle 比赛，学会特征工程+模型调参基本流程，输出分析笔记
春季学期（3–6月）可视化+竞赛
系统学 Tableau/Power BI；参加正大杯市场调查大赛或挑战杯
暑假（7–8月）独立项目
做完整独立数据分析项目（如成都二手房价格分析），发表到知乎/博客

大三 · 实战期

关键词：机器学习入门、实习经历、项目作品集建设、确定方向

📚 课程学习重点

  • 机器学习 / 数据挖掘 — 回归、决策树、随机森林、XGBoost、神经网络入门
  • 时间序列分析 — ARIMA、季节性分解、金融/零售预测场景
  • 抽样调查 — 问卷设计、分层抽样、误差估计
  • 大数据技术基础 — Hadoop/Spark 概念入门，了解分布式计算基本思路

🛠️ 课外自学路线

  • Scikit-learn 完整学习 + XGBoost / LightGBM 实战
  • 机器学习项目全流程：数据清洗→EDA→特征工程→建模→评估→报告
  • 学习 A/B 测试原理与业务指标体系（DAU/MAU/留存/转化/ARPU/LTV）
  • 建设个人博客（GitHub Pages / 知乎），发布分析文章 5+ 篇
  • 学习 Docker 基础 + Linux 命令行基础操作

💼 实习准备

  • 大三上（9–12月）：打磨简历 + 整理项目作品集；开始投递寒假实习
  • 大三寒假（1–2月）：争取第 1 段实习（数据分析助理 / BI 实习生）
  • 大三下（3–6月）：继续投递暑期实习，同时准备 CDA 数据分析师认证
  • 大三暑假（7–8月）：重点暑期实习！争取大厂或中厂的正式暑期实习岗位
  • 目标企业类型：互联网（运营/产品数据分析）、金融（风控/征信）、零售（供应链/用户分析）、咨询公司
  • 简历投递量目标：寒假 50+ 份，暑期 80+ 份

📊 推荐进度

机器学习（Scikit-learn）大三上
A/B测试&指标体系大三下
实习经历2段

🏆 可交付成果

至少2段对口实习GitHub项目 ≥ 6CDA 证书博客文章 ≥ 5篇LeetCode 200+熟悉A/B测试

大四 · 冲刺期

关键词：秋招全力以赴、毕业论文、深度项目、软技能补齐

🎓 大四上学期 · 秋招黄金期（9–11月）

  • 8 月前完成简历终版（中英文两版）+ 作品集网站上线
  • 梳理常见数据分析面试题：统计学基础 + SQL 手写 + Python 编程 + 业务分析 Case
  • 每周投递 15–20 家，海投 + 内推双线并行；牛客网/脉脉找内推人
  • 每次面试后立即复盘，建立个人面试题库文档
  • 目标岗位：数据分析师 / BI 工程师 / 商业分析师 / 数据运营

📝 大四下学期 · 收尾与提升（2–6月）

  • 高质量完成毕业论文（选题建议：基于实际业务数据的建模分析）
  • 春招补录窗口（3–4月），如果秋招不理想再做冲刺
  • 学习业务思维：精读《金字塔原理》《用数据讲故事》
  • 了解 AIGC + 数据分析的结合方向（LLM 辅助分析、Prompt Engineering）
  • 准备职前技能：职场沟通、邮件写作、PPT 汇报

🏆 毕业前最终目标

手握至少 1 个 Offer毕业论文优秀GitHub项目 ≥ 8LeetCode 250+完整作品集网站2 段实习经历
